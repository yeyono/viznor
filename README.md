# VizNor

SSB uten kjedsomheten. Live tall fra PxWebApi v2 som wow-fakta og grafer.

**Ikke en offisiell SSB-side.** Data: CC BY 4.0.

## Publiser på Netlify (ett klikk)

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/yeyono/viznor)

1. Logg inn på [Netlify](https://app.netlify.com) (GitHub-innlogging går fint).
2. Trykk knappen over, eller: **Add new site → Import an existing project → GitHub → viznor**.
3. Publish directory: `.` — ingen build-kommando.
4. Deploy. Du får en adresse som `https://noe-tilfeldig.netlify.app`.

Deretter kan du under **Domain settings** koble på f.eks. viznorge.no.

## Lokalt

Åpne `index.html` i nettleseren. Siden henter data direkte fra SSB.
